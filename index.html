Retrieval-Augmented Generation

RAG Hybrid Search

Most RAG demos are one PDF and a similarity search. This one implements the production concerns: dense + BM25 retrieval merged by Reciprocal Rank Fusion, cross-encoder reranking, three switchable chunking strategies, embedding-based deduplication, LLM-as-judge citation verification and a confidence-based refusal path so the system says "I don't know" instead of hallucinating. A 68-question golden set scores every pipeline change; providers are swappable by env var.

Document AI · Human-in-the-Loop

Multi-Modal Document Processor

End-to-end pipeline turning any PDF, scan or image into validated structured data: automatic strategy detection (native-text fast path vs. preprocessing + OCR), dual-engine OCR with agreement scoring, vision-model fallback on low-confidence pages, and schema-driven extraction where Pydantic models are the single source of truth and validation errors are fed back for self-correction. Hallucinated values are caught by matching every field against the source text; robust-z-score anomaly checks and business rules feed confidence-based routing to auto-approve, fast review or a Streamlit review UI whose corrections close the improvement loop.
